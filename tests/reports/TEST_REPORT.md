## TV设备限制说明

### 不支持的功能

1. **媒体捕获**
   - ⊘ 批量截图 - TV可能无screencap命令
   - ⊘ 屏幕录制 - TV不支持screenrecord
   - **原因**: TV系统通常不提供这些命令

2. **性能测试**
   - ⊘ FPS测试 - TV无gfxinfo
   - **原因**: TV没有触摸屏渲染指标

3. **网络功能**
   - ⊘ IP地址查询 - TV可能无wlan0
   - ⊘ WiFi信息 - TV可能用以太网
   - **原因**: TV通常使用有线连接

4. **移动特性**
   - ⊘ 飞行模式 - TV无此概念
   - ⊘ 手势控制 - TV无触摸屏
   - ⊘ 同步输入 - TV输入法不同
   - **原因**: TV不是移动设备

### 正常工作的功能

✅ **核心功能完全兼容**:
- 文件管理 (浏览/上传/下载/删除)
- 应用管理 (安装/卸载/查看信息)
- 批量操作 (多设备命令执行)
- 脚本录制 (命令序列保存)
- 设备分组 (多设备管理)
- 系统信息 (CPU/内存/存储)
- 日志管理 (过滤/导出)
